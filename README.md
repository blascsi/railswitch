# Railswitch

Railswitch is an easy to use but full featured Feature Flag manager and evaluator.

> [!IMPORTANT]
> The source of truth for this project is currently my own Forgejo instance. The code on Github is a mirror of the `main` branch of that repository, to make the source available to the public. The state of the Github repo does not accurately represent the current development status of the project.

## Goals

- Ease of use: The goal of the project is to be powerful enough to be used by engineering teams, but be straightforward enough so non-engineering people can manage it when needed.
- Local evaluation: Flag state is replicated locally, and executed on your devices.
- Gradual rollouts: Set up pre-determined percentage bumps in a flag, to slowly roll out features to users
